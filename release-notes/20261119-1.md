This release includes upstream tonioni/pfs3aio#39, tonioni/pfs3aio#40, tonioni/pfs3aio#41, tonioni/pfs3aio#42, tonioni/pfs3aio#43, tonioni/pfs3aio#44, tonioni/pfs3aio#45, tonioni/pfs3aio#46 and tonioni/pfs3aio#48.

- `pfsdoctor` is now bundled with tools `setdeldir`, `setfnsize` and `setlargefile`
- A file deleted since the last update stays in .DELDIR and can be recovered until its blocks are reused.
- `setdeldir` can set `.DELDIR` size again
- A power cut right after an update no longer leaves old metadata blocks allocated until `pfsdoctor` repairs the volume.

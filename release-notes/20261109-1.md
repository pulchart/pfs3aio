Includes upstream tonioni/pfs3aio#14, tonioni/pfs3aio#20, tonioni/pfs3aio#21, tonioni/pfs3aio#22 and tonioni/pfs3aio#23:
- Fixed: a disk or memory error during a write no longer reuses the blocks of the last consistent state. Further writes are refused with 213 Disk not validated.
- Fixed: a damaged volume with oversized directory entries, a corrupt reserved block table or an anode index beyond the 16 bit limit is rejected instead of corrupting memory.
- Changed: if the buffers are not set (the HDToolbox default of 30), the handler uses 150 with Fast RAM and 70 without. Was 150.
- Changed: the handler is a single code hunk (was two), for old RDB loaders that cannot load more than one.
- Changed: the builds are about 14 percent larger, from the added checks.

This release includes upstream tonioni/pfs3aio#49.

- `pfsdoctor` repairs a damaged directory block without losing the files in the other blocks of that directory.
- `pfsdoctor` repairs a damaged rootblock extension from its backup without rolling back files written or deleted since.
- `pfsdoctor` sets a wrong `.DELDIR` size to the blocks the deldir really has.
- `pfsdoctor` reports every repair of the reserved bitmap.
- `pfsdoctor` needs much less memory and time on volumes with 4096 byte blocks.
- The tools return a defined exit code, so scripts can rely on it.
